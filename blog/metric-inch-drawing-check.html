Metric and Inch Dimensions in a Steel Cutting Package

Make the governing units and accepted conversions explicit before a drawing reaches production.

SHANDONG DAZHI28 October 2026

Choose one governing dimensional basis

An inquiry may include a metric drawing, an inch-based parts list and a CAD file with no obvious unit declaration. State which document and unit system govern manufacture. Treat converted dimensions as supporting information unless the purchaser explicitly accepts them as the production basis. A label saying both metric and imperial does not resolve conflicts between rounded values.

Check files with a known reference

Ask the processor to confirm file scale against a clearly dimensioned reference feature before nesting. Review hole sizes, bend references and tolerances as well as the overall outline. Decimal precision can be lost during conversion, while a displayed dimension can remain unchanged even when imported geometry has the wrong scale. Record the agreed check with the file revision.

Approve conversions through the drawing process

Put any accepted converted dimensions on a controlled drawing or schedule. Do not rely on a separate spreadsheet maintained by one production operator. Where a discrepancy affects fit or a specified tolerance, refer it to the responsible designer before cutting. The inspection record should identify the same governing units, rather than reporting a different rounded value after manufacture.

A practical record structure

RecordInformation to agree
Drawing unitsExplicit governing system
CAD scaleKnown reference feature
ToleranceAccepted value after conversion
InspectionSame units as the released drawing

Before closing the review

  • Declare the governing units.
  • Confirm imported geometry scale.
  • Approve conversions before manufacture.
