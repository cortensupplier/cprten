Managing CAD Files and PDF Proofs for Cut Steel Parts

Control the relationship between production geometry, readable drawings and the accepted revision.

SHANDONG DAZHI28 October 2026

Link geometry to a readable drawing

A production CAD file and its PDF proof should identify the same part and revision. The CAD file supplies geometry, while the readable drawing explains dimensions, tolerances, orientation and notes. Keep them together in the release package. If they differ, establish which file is corrected before accepting the order for manufacture rather than leaving the workshop to choose.

Remove ambiguity from filenames

Use a stable part mark and explicit revision in the filename or controlled register. Identify preliminary quotation files separately from released production files. Avoid several attachments all named final, because recipients can easily save them in different folders and continue using an earlier copy. Tell the processor which files replace earlier issues and request acknowledgement of the accepted package.

Archive the accepted release

Record the release date, issuer and supplier acknowledgement. Keep the package used for manufacture available when inspecting the finished parts. If a drawing changes after release, use a change instruction that identifies affected quantities and work status. Deleting an obsolete file from a shared folder is not evidence that downloaded copies have been withdrawn from production.

A practical record structure

RecordInformation to agree
Part markSame identity in CAD and PDF
RevisionAccepted issue for both files
StatusQuotation or production release
AcknowledgementRecipient and confirmation date

Before closing the review

  • Check CAD and PDF together.
  • Separate preliminary and released packages.
  • Archive the accepted manufacturing issue.
