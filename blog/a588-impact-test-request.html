When an A588 Plate Order Needs Additional Impact Testing

How to state optional project testing in an A588 plate purchase package without assuming it is automatically included.

SHANDONG DAZHI5 November 2026

Begin with the project requirement

The engineer should identify whether impact testing is required for the actual structure, thickness and service temperature. A request for ASTM A588 alone does not tell a supplier which additional project test, specimen orientation or acceptance criterion is intended.

Write a test schedule

List the required test method, temperature, location, frequency, acceptance basis and witnessing arrangement in the purchase documents. Confirm feasibility before cutting or allocating plate. Do not add a vague “impact tested” note after material has already been shipped.

Separate material and fabrication records

A mill test, a fabrication procedure qualification and an inspection of the completed assembly answer different questions. Ask for each record explicitly if the project needs it. Keep the test pieces and results linked to the relevant heat and plate thickness.

Control exceptions

If an offered heat lacks the required report, request an approved alternative test plan or material substitution from the engineer. Record the decision before releasing that plate to fabrication. Commercial urgency should not silently change the acceptance basis.

Test request example

A project schedule may require a test report before the steel is released to fabrication. Mark that release point in the purchase order and define who reviews it. If the test request arrives only after the parent plate is consumed, the link between test location and shipped part may be difficult to verify.
