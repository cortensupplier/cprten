Mill Origin, Seller Address and Dispatch Location in a Steel Inquiry

Ask for the right location information instead of treating several different addresses as interchangeable.

SHANDONG DAZHI29 October 2026

Stored plate with visible material identification marks. Photograph for material or application context; component details follow the project drawing.

The steel mill location, seller address, processing location and dispatch point can be different. Each answers a different purchasing question. Clarify which information the project requires and ask for the corresponding evidence instead of inferring material origin from a warehouse photograph or email signature.

Define the origin requirement in the inquiry

If the purchase has a specified mill, source or origin requirement, state it before quotation and identify the documents the purchaser needs to review. Have the appropriate project or trade adviser confirm any formal documentation requirements. The supplier should not have to guess whether a general location question concerns metallurgy, transport planning or a project procurement condition.

Map the material route

Request the proposed source material, processing location and final dispatch point as separate items. Where cutting or forming is subcontracted, identify how the material records will stay connected to the supplied parts. A different processing address does not by itself establish that the base material has changed, but the route should be clear enough to check the required records.

Compare evidence with the actual supplied pieces

Use the material identification and accepted document package to connect the source information to the order. Confirm how split heats or replacement stock are recorded. Do not treat a sample certificate as proof for a later shipment with different identifiers. Any proposed source substitution should pass through the agreed purchase approval process.

Use the dispatch location for logistics planning

Send the transport party the location from which the completed shipment will actually leave, along with readiness and loading details. Keep that information separate from the seller contact address. If the dispatch point changes, update the transport instructions and review the effect on the agreed collection arrangement without rewriting unrelated material records.

Before you release the next stage

  • State which origin information is required.
  • Connect source records to supplied material identifiers.
  • Confirm the actual dispatch address before collection.
