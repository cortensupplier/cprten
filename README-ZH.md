## 上传 GitHub Pages

1. 解压 `SHANDONG-DAZHI-Weathering-Steel-GitHub-Pages.zip`。
2. 新建一个独立 GitHub 仓库，例如 `dazhi-weathering-steel`，以免覆盖原镍基合金站。
3. 上传解压后的**全部文件和文件夹**到仓库根目录；让 `index.html` 位于根目录，同时保留 `.nojekyll`。GitHub Pages 不会自动展开 ZIP，不能只上传 ZIP 本身。
4. 在仓库 Settings → Pages 中选择 Deploy from a branch，选择 `main` 分支及 `/ (root)`，保存。
5. 等待 Pages 部署完成，打开 GitHub 显示的网站地址。网站使用相对链接，可部署在 `https://用户名.github.io/仓库名/`。

这是纯静态网站，不需要安装 Node.js、运行构建命令或配置数据库。可直接编辑包内 HTML / CSS / JavaScript。

## RFQ 如何查看、发送

进入网站右上角 **Request a Quote**，或直接访问 `rfq.html`。产品页的 **Request this material** 会自动带入产品。

填写联系人、公司、邮箱、材料、尺寸、数量、项目说明并勾选说明后，点击 **Review RFQ summary**。摘要显示在表单下方。

- **Open email**：打开客户设备的默认邮件应用，收件人为 `cs@jiujianggrp.com`。客户检查后点击发送。
- **Open WhatsApp**：打开 `+86 150 9506 3690` 的对话并带入摘要，客户检查后点击发送。
- **Copy summary**：复制完整询价内容，可粘贴到网页邮箱或其他邮件应用。
- **Download .txt**：请求浏览器下载询价文本，可作为附件发送。下载位置由客户浏览器决定。
- 内容较长时，邮件按钮会改为提示粘贴摘要或附上下载文件，避免邮件链接长度限制。
- 图纸在邮件或 WhatsApp 中另行添加，网页不上传附件。

**当前不会自动发邮件，也没有询价后台。** 只有客户在邮件或 WhatsApp 中实际发送后，您才会收到。GitHub Pages 本身只是静态托管；若要实现“表单提交后自动到邮箱”，后续需要接入表单服务或后端邮件接口，并确认该服务的收件邮箱。邮箱密码、SMTP 密钥不能放进静态网站。

RFQ 数据不保存到网站服务器或浏览器本地存储，刷新或关闭页面可能丢失未发送的内容。浏览器自动填充或恢复行为由浏览器设置控制。
